# LoggerLibrary

A Java-based logging library project created to explore the fundamentals of logging, reusable library development, and software design in Java.

## 📌 Overview

LoggerLibrary is a learning project focused on understanding how logging libraries can be designed and implemented in Java.

Logging is an essential part of software development. It helps developers track application execution, identify errors, troubleshoot issues, and understand application behavior.

The goal of this project is to explore the concepts behind building a reusable logging library rather than relying exclusively on existing logging frameworks.

## 🎯 Objectives

- Understand the fundamentals of application logging.
- Explore how a reusable Java logging library can be structured.
- Practice object-oriented programming and Java development.
- Understand how logging functionality can be separated from application business logic.
- Improve knowledge of software design and reusable components.

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK).
- IntelliJ IDEA or another Java-compatible IDE.
- Git.

### Clone the repository

```bash
git clone https://github.com/nikitamarne388/LoggerLibrary.git
```

Navigate to the project directory:

```bash
cd LoggerLibrary
```

### Open the project

1. Open IntelliJ IDEA.
2. Select **File → Open**.
3. Choose the cloned `LoggerLibrary` directory.
4. Allow IntelliJ to load and configure the project.
5. Review the source code and available tests.

### Build and Run

Follow the build configuration included in the repository. If the project uses Maven, you can build it with:

```bash
mvn clean package
```

This command applies only if a `pom.xml` file is present and Maven is configured for the project.
